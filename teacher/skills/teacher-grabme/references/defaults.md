# 默认值（Defaults）

**能提供合理默认值，就不要让用户配置。**

下面这些值，AI **静默填上**，不提问、不确认、不罗列。它们只在两种情况下被提起：

1. 写进 Requirement Brief 的 `assumptions`，让老师有机会纠错；
2. 老师主动问"你打算怎么做"时，用一句 Reverse Brief 说出来。

默认值是**起点**，不是拒绝修改：老师一说就改，改完记进台账，同类问题此后不再问。

---

## 通用默认值（所有任务）

| 槽位 | 默认值 | 说明 |
|---|---|---|
| `audience.grade` / `audience.textbook` | 取记忆中的本学年设置 | 记忆缺失时按消息推断 |
| `language` | 简体中文 | 术语与教材一致 |
| `output_format` | 便于打印/投影的常规版式 | 不追问格式 |
| `answer_key` | 出题类任务默认**附答案** | 老师几乎总要 |
| 交代假设的方式 | **一句**可纠正的 Reverse Brief | 不做假设清单式汇报 |
| 不确定的内容 | 不编造；写进 `unresolved` | 宁可留白 |

---

## `lesson_design` 默认值

| 槽位 | 默认值 |
|---|---|
| `duration` | 一节课 45 分钟（小学按 40 分钟） |
| `lesson_type` | 新授课 |
| `goal_orientation` | 以"先讲清楚、能解释现象"为主，兼顾考点 |
| `activity_preference` | 安排 **1** 个低风险活动（同桌讨论或观察推理），不排复杂分组任务 |
| `assessment_form` | 结尾 1 个快速检查（口答或两道小题） |
| `key_difficulty` | 按教材与课标通例取本节最常见障碍 |
| `differentiation` | 给一条保底要求，不做完整分层 |
| `output_format` | 教学设计文档：目标 → 环节与时间 → 关键提问 → 板书/要点 → 当堂检查 |
| `homework` | 不留或只留一道对应练习 |

**一句 Reverse Brief 示例**：
> "我先按高一、45 分钟、新授课，少讲授、多让学生自己推来设计，结尾放一道快速检查。
> 如果没有特别要求我就按这个展开。"

---

## `assessment_design` 默认值

| 槽位 | 默认值 |
|---|---|
| `coverage` | 本次考试进度范围（期中 → 前两章；单元测 → 本单元） |
| `total_score` | 100 分 |
| `duration` | 45 分钟（期中期中段考按 90 分钟） |
| `item_types` | 选择题 + 填空题 + 2 道综合/实验题 |
| `difficulty_mix` | 约 7 : 2 : 1（基础 : 中档 : 提高） |
| `blueprint` | 按知识点平均分布，重点章节略加权 |
| `answer_key` | 附参考答案与简要解析 |
| `reuse_policy` | 全部新编，不直接搬往年题 |
| `layout` | 考试友好版式：页眉留姓名班级栏，题干与选项分开，配图清晰 |
| `exam_purpose` | 从老师原话判断（"期中试卷"→期中） |

**一句 Reverse Brief 示例**：
> "我按期中进度（前两章）、100 分、45 分钟、7:2:1 的难度配比来出一份，选择和填空为主，
> 最后两道综合题，附答案和解析。如果范围不止前两章，你说一声我改。"

## `ppt_design` 默认值

| 槽位 | 默认值 |
|---|---|
| `slide_count` | 15–20 页（一节课） |
| `slide_flow` | 情境导入 → 逐层推进 → 小结 → 当堂练习 |
| `content_density` | **一个点一页**，每页不超过 6 行要点 |
| `visual_assets` | 只放支撑理解的示意图；不堆装饰图 |
| `interaction_points` | 插入 1–2 页提问或练习页 |
| `formula_rendering` | 公式保持可编辑（不使用图片贴公式） |
| `theme_color` | 投影友好的高对比深色字浅色底，正文黑体、标题加粗 |
| `font_size` | 正文不小于 24 pt，投影下清晰 |
| `projection_notes` | 每页附 2–3 句备注页讲稿 |
| `duration` | 复用同会话里已确定的课时长度 |

**一句 Reverse Brief 示例**：
> "课件我按一节课 15–20 页、一个点一页、投影能看清的大字来做，中间插两页提问。
> 有学校模板的话你发我，没有我就用通用版式。"

## `worksheet_design` 默认值

| 槽位 | 默认值 |
|---|---|
| `use_stage` | 课中随堂或课后巩固 |
| `item_count` | 8–12 题（一节课的练习量） |
| `question_types` | 与本课内容匹配：选择 + 填空 + 简答 |
| `difficulty_mix` | 约 6 : 3 : 1 |
| `answer_key` | 附答案，不附详解 |
| `scaffolding` | 首题给一个示例或提示 |
| `differentiation` | 标出 1 道选做（提高）题 |
| `layout` | 留足书写空白，一页不超过 6 题 |

**一句 Reverse Brief 示例**：
> "学案我按随堂用、10 题左右、基础为主、最后放一道选做来做，答案附在最后一页。
> 如果是要学生带回家写，告诉我我把题量调一下。"

---

## 默认值的使用规则

1. **默认值不占用提问预算。** 预算只给真正会改变结果的问题。
2. **默认值必须可见。** 写进 `assumptions`，或用一句 Reverse Brief 说出来——
   悄悄做了但不说，等于剥夺老师的纠错机会。
3. **默认值不覆盖老师的话。** 老师说了 30 分钟，就是 30 分钟，不许回落到 45 分钟。
4. **默认值不覆盖高置信记忆。** 记忆里是"高二、人教版选择性必修一"，就用它。
5. **一次纠正 = 长期约束。** 老师把某个默认值改过之后，本会话内不再回退它，
   也不为同一个槽位再提问。
6. **默认值与实际矛盾时坦白说。** 例如按 15–20 页做了但内容需要 25 页，
   要说明"内容比预期多一些，多做了几页"，而不是偷偷压缩。
