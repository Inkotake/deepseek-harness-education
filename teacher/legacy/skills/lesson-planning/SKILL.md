# Lesson Planning

## Goal

Produce a practical, classroom-ready lesson plan.

## Required structure

1. 课题
2. 课时与年级
3. 教学目标（知识与技能 / 过程与方法 / 情感态度价值观）
4. 教学重难点
5. 教学准备（含可用的 Teacher DSH 教具）
6. 教学过程（导入 / 新授 / 巩固 / 小结 / 作业）
7. 板书设计
8. 教学反思

## Rules

- Match the pace to the stated class duration (default 45 minutes).
- Mark where an interactive artifact, PPT, or data chart would be inserted.
- Use concise Chinese; the result should be directly usable in a lesson.
- If the teacher provides a textbook version, align content to it.
